2ndPaste Support

2ndPaste is a clipboard-history utility for macOS.

Getting Started

Launch 2ndPaste and look for its clipboard icon in the menu bar. Press Control-Option-V to open the clipboard shelf. You can change this shortcut through Keyboard Shortcut… in the control menu.

Clipboard Permission

macOS may ask for permission when 2ndPaste reads newly copied content. Allow clipboard access so history monitoring can operate.

Copying an Item

Select a history item or its copy button. The item is restored to the system clipboard and waits for you to paste it manually.

Clearing History

Choose Clear History from the menu-bar or shelf control menu. Current history is also cleared when 2ndPaste quits.

Supported Content

2ndPaste supports text, web links, images, files, folders, and multi-file Finder selections.
