# Echoes of Eternity

Echoes of Eternity is now a static browser game designed to run directly from this repository on GitHub Pages.

## Hosting model

- No backend server
- No database
- No npm build step
- Persistent best score and echo trails stored in `localStorage`

- `/home/runner/work/blog/blog/projects/games/echoes-of-eternity/index.html`
- `/home/runner/work/blog/blog/projects/games/echoes-of-eternity/style.css`
- `/home/runner/work/blog/blog/projects/games/echoes-of-eternity/main.js`

## Controls

- `W` / `S` or `↑` / `↓` to steer
- `Space` or pointer/touch hold to boost
- `Enter` to restart after a collapse
